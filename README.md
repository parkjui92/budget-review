# budget-review — 예결산 검토보고서 작성팀

[![Version](https://img.shields.io/badge/version-0.2.0-blue.svg)](.claude-plugin/plugin.json)
[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)
![Claude Code](https://img.shields.io/badge/Claude_Code-Plugin-purple.svg)

사업 한 건의 **결산·예산안 검토보고서 검토항목 초안**을 다섯 AI 팀원이 나눠 쓰는 [Claude Code](https://claude.com/claude-code) 플러그인입니다.
국회사무처 의정연수원 「생성형 AI 업무 활용(심화): Claude Code — 예결산 검토보고서 에이전트 설계 및 업무 자동화」(2026. 10.) 교육용으로 만들었습니다.

검토설계자가 쟁점을 짜고, **검수관이 읽기 전용으로 판정**하고, 사람이 쟁점을 승인한 뒤에야 조사가 시작됩니다.
집필이 끝나면 **검산기가 표를 기계로 다시 계산**하고, 통과하지 못하면 산출을 내보내지 않습니다.

## 설치

Claude Code에 이렇게 말하면 됩니다.
```
github.com/parkjui92/budget-review 플러그인 설치해줘
```
직접 입력하려면
```
/plugin marketplace add parkjui92/budget-review
/plugin install budget-review@budget-review
```
설치 뒤 Claude를 다시 시작하면 팀원이 불려 나옵니다.

## 이렇게 씁니다

```
○○사업(보조금)의 2025회계연도 결산 검토보고서 검토항목 초안을 써줘. 관점은 집행 부진과 이월·불용 반복이야
```
팀이 도는 동안 작업 폴더의 `_workspace/`에 단계별 파일이 하나씩 쌓입니다. 팀장이 각 단계의 시작과 끝을 한 줄씩 알려 줍니다.

| 검토설계자 | 사업 개요 파악, 재원 유형 판정, 착안사항 대조, 검토 쟁점·목차 설계 | 읽기·쓰기 | `01_검토설계.md` |
| 검수관 | 관문① 설계 판정, 관문② 초안 검수(쟁점 누락·근거·반박 유무·문체) | **읽기 전용** | `02_설계판정.md` · `05_검수판정.md` |
| 자료조사관 | 열린재정·열린국회정보·사업설명자료·성과보고서·감사원·PIMAC에서 수치와 근거 수집, 출처·조회일 병기(여럿이 동시에) | 검색·읽기·쓰기 | `03_근거장부.md` |
| 집필가 | 검토보고서 문체로 검토항목 집필 | 쓰기 | `04_검토보고서.md` |
| 검산 게이트 | 단위·세로 합계·가로 관계식·집행률·증감·분모·음수 표기 검산, 불통과면 산출 보류 | 스크립트 | `04b_검산결과.md` |
| 변환가 | 예결위 편집 양식 한글 문서로 조판 | 쓰기 | `06_검토보고서.hwpx` |

## 공정

```
요청 원장 → 검토설계 → ◆관문①(설계 판정) → ★쟁점 승인(사람) → 자료조사(병렬) → 집필
        → ◆검산 게이트 → ◆관문②(초안 검수) → 한글(.hwpx) 변환 → 사람이 판정할 목록
```
- **관문①** — [필수] 지적이 하나라도 있으면 NO-GO. 설계자가 한 번 고친다
- **★쟁점 승인** — 쟁점을 넣고 빼고 순서를 바꿀 수 있다. **승인 전에는 조사로 넘어가지 않는다**
- **검산 게이트** — 어떤 경우에도 생략하지 않는다. 두 번 고쳐도 불통과면 산출을 보류하고 사람에게 묻는다
- **관문②** — 본문의 숫자를 근거 장부와 하나씩 맞추고, **반박 없는 지적**을 [필수]로 잡는다
- "빨리"라고 하면 관문은 그대로 두고 개정 왕복만 줄이는 경량 모드로 돈다

## 준비물

| 무엇 | 필요한 곳 | 없으면 |
|---|---|---|
| Python 3 | 검산 게이트(표준 라이브러리만, 설치할 것 없음) | 검산을 할 수 없다 — 필수 |
| [kordoc](https://github.com/chrisryugj/kordoc) MCP (Node.js 20 이상) | 한글 자료 읽기, `.hwpx` 변환 | 마크다운까지 정상 산출, 변환만 보류 |
| 인증키(`.env`) | 열린재정 OpenAPI·열린국회정보·국가법령정보 | 웹 조회와 키 없는 조회(열린국회정보 5건)로 진행 |

인증키는 작업 폴더의 `.env`에 둡니다. **채팅창에 붙여 넣지 않습니다.** 키 이름: [skills/budget-sources/SKILL.md](skills/budget-sources/SKILL.md)

## 교재와의 관계 · 저작권

- 검토 기준(`skills/review-criteria/references/`)은 국회의정연수원 「예결산검토 표준교재」(2024) 7권
  (세입·보조금·출연금·SOC·특별회계·기금·공공기관)의 분석 착안사항을 **점검 질문으로 새로 쓴 것**입니다.
  **교재 원문은 수록하지 않았습니다.** 질문마다 교재 쪽을 달아 두었으니 **원문은 교재에서 확인**하십시오. 교재의 저작권은 국회사무처에 있습니다
- 검토보고서 문체·번호 체계·지적의 짜임 규격(`skills/review-writing`)은 2025회계연도 결산 검토보고 6개 분책과 2026년도 예산안 검토보고 6권을 같은 방법으로 계량해 뽑은 것입니다. 검토항목 제목 예시 몇 줄 외에 검토보고서 원문은 수록하지 않았습니다
- 감사원 감사결과는 공공누리 제4유형(변경금지)입니다. 발간물에 실을 때는 이용조건을 확인하십시오
- 공정·관문·판정서 방식은 같은 저자의 [policy-research-kit](https://github.com/parkjui92/policy-research-kit)에서 가져와 예결산 검토보고서에 맞게 바꿨습니다

## 한계

- **초안입니다.** 지적으로 올릴지, 부처 해명을 받아들일지, 어떤 어조로 쓸지는 사람이 정합니다
- **검산 통과는 산술이 맞다는 뜻일 뿐입니다.** 원자료에서 잘못 옮긴 값, 회계연도 착오, 조문 번호, 인용 문안은 원문 대조로만 잡힙니다
- 검수관도 같은 계열의 AI라 비슷한 착각을 할 수 있습니다. 관문은 오류를 줄이지만 없애지 못합니다
- **공개 자료를 전제합니다.** 미공개 부처 제출자료·심사 전 내부자료·개인정보를 넣지 마십시오
- 검토 기준의 법령·제도는 교재 기준 시점(2024년 8월)입니다. 조문은 인용 전에 현행 원문으로 확인합니다
- 문체 규격은 예결위의 **2025회계연도 결산**(6권)과 **2026년도 예산안**(6권) 검토보고서 계량에서 나왔습니다. 상임위 예비심사검토보고서는 위원회마다 골격이 달라, 그 위원회의 직전 보고서를 입력으로 주면 그 골격을 따릅니다
- 한글 변환은 실물 검토보고서(.hwpx)를 주면 그 **표 서식**을 따릅니다. 머리말·쪽번호·표지 같은 편집 요소는 한글에서 손으로 맞춰야 할 수 있습니다
- 자료원 경로는 2026-09-13 기준입니다. 기관·시스템 개편으로 바뀔 수 있습니다
