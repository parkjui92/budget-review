# 2026-10-12 로컬 고도화 검토

비공개 유지. 아직 원격 저장소에 반영하지 않았으며 승인 후에만 반영합니다.

숫자에서 쉼표·%·원을 무조건 지우던 처리를 바꿨습니다. `1,2`나 `10%20`은 숫자로 추정하지 않고 수치 열의 표기 오류로 보고하며, `+12.5%`는 올바르게 읽습니다.

검증: `python3 -m unittest discover -s skills/fiscal-rules/tests -q` — 3개 통과(13개 표기 사례 포함). 기존 `fiscal_check.py --selftest` — 31/31 통과.
