지킬 것

· 키를 채팅창에 붙여 넣지 않음 · 대화 기록에 남음

· 작업 폴더의 .env 파일에 내 손으로 적고, AI에게 그 파일을 열어 보게 하지 않음

· 부서 저장소에 올릴 때는 .gitignore에 .env 한 줄 · 노출되면 재발급

· 유료 키(검색 · 모델 API)는 결제 수단이 묶여 있으니 한도부터 설정

OPENFISCAL_KEY= # 열린재정 OpenAPI ASSEMBLY_KEY= # 열린국회정보 LAW_OC= # 국가법령정보 공동활용 인증값 DATA_GO_KR_KEY= # 공공데이터포털(나라장터 등) KOSIS_KEY= # KOSIS
